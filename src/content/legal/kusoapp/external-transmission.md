株式会社アリガトサン(以下「当社」)は、アプリ「KUSOMEGANE PLUS」(以下「本サービス」)において、利用者の端末から次の外部の事業者へ利用者に関する情報を送信しています。

## 送信先と送信される情報

### 1. PostHog(利用状況の分析)

| 項目 | 内容 |
|---|---|
| 送信先 | PostHog Inc. |
| 送信される情報 | 当社が発行する利用者 ID(ランダムな英数字)、閲覧した画面、アプリ内での操作(ガチャを引いた等の出来事)、端末・OS の種類、アプリのバージョン、IP アドレス |
| 当社の利用目的 | 利用状況を把握し、本サービスを改善するため |
| 送信先での利用目的 | 当社への分析機能の提供 |
| 送信の停止 | 現在、アプリ内で送信を停止する設定は設けていません |
| 送信先のプライバシーポリシー | https://posthog.com/privacy |

氏名・メールアドレス・住所等は送信しません。

### 2. Sentry(不具合の監視)

| 項目 | 内容 |
|---|---|
| 送信先 | Functional Software, Inc. |

| 当社の利用目的 | 不具合を発見し修正するため |
| 送信先での利用目的 | 当社への不具合監視機能の提供 |
| 送信先のプライバシーポリシー | https://sentry.io/privacy/ |
